# Файлы и форматирование

На этой странице про то, как выглядят сообщения бота: разметка текста, фото и файлы, ответы на сообщения и статус «печатает…».

## Форматирование текста

Текст сообщений отправляется как HTML в обоих мессенджерах:

```python
await ctx.reply("<b>Жирный</b>, <i>курсив</i>, <code>код</code> и <a href=\"https://example.com\">ссылка</a>")
```

Теги, которые понимают оба мессенджера:

| Тег | Что делает |
|---|---|
| `<b>` | жирный текст |
| `<i>` | курсив |
| `<u>` | подчёркнутый |
| `<s>` | зачёркнутый |
| `<code>` | моноширинный текст внутри строки |
| `<pre>` | блок моноширинного текста |
| `<a href="...">` | ссылка |

Это не HTML из браузера: абзацев, списков, заголовков и таблиц в мессенджерах нет. Перенос строки делается обычным символом `\n`, а не тегом `<br>`.

### Экранирование

Раз текст это HTML, символы `<`, `>` и `&` в нём имеют особый смысл. Пока текст пишете вы, это не проблема. Но как только в сообщение попадает что-то снаружи, эти символы могут оказаться там, где вы их не ждали.

Простой пример: человек с именем `Аня <3`. Сообщение `Привет, Аня <3!` мессенджер попробует разобрать как HTML, найдёт незакрытый тег и откажется его принимать.

Пример хуже: человек ставит себе имя `<a href="https://evil.example">Нажмите сюда</a>`. Бот пишет в чат поддержки «Новое обращение от» и это имя, и в сообщении бота появляется настоящая ссылка, которой там быть не должно.

Поэтому всё, что пришло снаружи, перед вставкой в сообщение пропускайте через `escape()`:

```python
from matele import escape

await ctx.reply(f"Вы написали: <b>{escape(ctx.text)}</b>")
```

Снаружи приходит больше, чем кажется:

- текст сообщения (`ctx.text`) и аргументы команды (`ctx.args`);
- имя и имя пользователя (`ctx.user.name`, `ctx.user.username`);
- имена файлов;
- всё, что вы достали из базы, если когда-то это ввёл человек.

Числа и строки, которые вы написали сами, экранировать не нужно.

`escape()` принимает любое значение и превращает его в строку. `escape(None)` возвращает пустую строку, поэтому отсутствующее имя не превратится в слово «None».

Для значения внутри атрибута, например адреса в `href`, нужно экранировать ещё и кавычки:

```python
await ctx.reply(f'<a href="{escape(url, quote=True)}">{escape(title)}</a>')
```

Если Telegram всё же не смог разобрать HTML, matele отправит то же сообщение простым текстом, чтобы оно не потерялось. Человек увидит теги как есть. Это страховка, а не замена экранированию.

### Простой текст

Отдельного режима «без разметки» нет, и он не нужен: текст, пропущенный через `escape()`, показывается ровно так, как написан.

```python
await ctx.reply(escape(text_from_anywhere))
```

## Отправка файлов

```python
from pathlib import Path

await ctx.reply_file(Path("cat.jpg"), kind="image", caption="Кот")
await ctx.reply_file(Path("clip.mp4"), kind="video")
await ctx.reply_file(Path("song.mp3"), kind="audio")
await ctx.reply_file(report_bytes, filename="report.csv")
```

Параметр `kind` говорит, как мессенджер покажет файл:

| `kind` | Как выглядит |
|---|---|
| `"image"` | фото с предпросмотром |
| `"video"` | видео с плеером |
| `"audio"` | аудио с плеером |
| `"file"` | файл для скачивания, значение по умолчанию |

Картинку можно отправить и как `"file"`. Тогда мессенджер не будет её сжимать, и она придёт документом.

Файл можно передать тремя способами:

- путём `Path`: имя файла возьмётся из пути;
- байтами: имя лучше указать в `filename`, иначе будет стандартное вроде `image.jpg`;
- открытым файлом в двоичном режиме.

Обратите внимание, что путь должен быть именно объектом `Path`, а не строкой.

Путь и открытый файл отправляются потоком и не читаются в память целиком, так что большие файлы не займут лишнюю память. Ограничения на размер задают мессенджеры.

У `reply_file` есть те же параметры `keyboard` и `quote`, что у `reply`, и подпись `caption`. Подпись тоже отправляется как HTML. В Telegram подпись не может быть длиннее 1024 символов, более длинную matele отправит отдельным сообщением следом за файлом.

Файл, который создаётся на лету, не обязательно сохранять на диск:

```python
import csv
import io


@dp.command("export")
async def export(ctx: Context):
    buffer = io.StringIO()
    writer = csv.writer(buffer)
    writer.writerow(["id", "сумма"])
    for order in await db.orders(ctx.user.id):
        writer.writerow([order.id, order.total])
    await ctx.reply_file(buffer.getvalue().encode("utf-8"), filename="orders.csv", caption="Ваши заказы")
```

## Ответ на сообщение

`quote=True` отправляет сообщение ответом на сообщение человека или на сообщение, где нажали кнопку:

```python
await ctx.reply("Принято", quote=True)
```

В группе это показывает, кому и на что отвечает бот. В личном чате обычно не нужно.

## Статус «печатает…»

Если ответ готовится дольше пары секунд, покажите, что бот работает. Иначе человек решит, что бот завис, и напишет ещё раз.

```python
async with ctx.typing():
    report = await build_report()
await ctx.reply_file(report, filename="report.pdf")
```

Статус обновляется каждые несколько секунд, пока выполняется блок, и пропадает, когда блок закончился. Если мессенджер не принял запрос статуса, хендлер это не прервёт: статус это украшение, и сбой в нём не должен ломать работу.

## Входящие файлы

Файлы, которые прислал человек, лежат в `ctx.message.attachments`. У каждого вложения четыре поля:

| Поле | Что в нём |
|---|---|
| `type` | `"image"`, `"video"`, `"audio"` или `"file"`. В Telegram ещё `"voice"`, `"animation"` и `"video_note"` |
| `filename` | имя файла. Может быть пустым, например у фото в Telegram |
| `token` | идентификатор файла в мессенджере |
| `url` | адрес для скачивания, есть только в MAX |

Поймать сообщения с файлами помогает фильтр `HasAttachment`:

```python
from matele import HasAttachment, escape


@dp.message(HasAttachment("file", "image"))
async def got_file(ctx: Context):
    att = ctx.message.attachments[0]
    content, filename = await ctx.bot.download_file(att.token, file_type=att.type, filename=att.filename, url=att.url)
    await storage.save(filename, content)
    await ctx.reply(f"Сохранил {escape(filename)}, {len(content)} байт")
```

`download_file` возвращает содержимое файла и его имя. Передавайте в него все четыре поля вложения, как в примере: разным мессенджерам для скачивания нужны разные из них.

Подпись к файлу лежит в `ctx.text`, как текст обычного сообщения.

В MAX в одном сообщении может быть несколько вложений. В Telegram в одном сообщении всегда один файл: альбом из пяти фото приходит пятью сообщениями.

### Ограничение размера

Файл скачивается в память целиком, поэтому размер ограничен: по умолчанию 50 МБ. Файл больше вызовет `BotApiError` с кодом 413. Без ограничения один присланный файл на несколько гигабайт мог бы занять всю память и уронить бота.

Лимит задаётся при создании клиента:

```python
from matele.max import MaxApi, MaxBot

max_bot = MaxBot(MAX_TOKEN, api=MaxApi(MAX_TOKEN, max_download=200 * 1024 * 1024))
```

`max_download=None` снимает ограничение. У Telegram есть и собственное: через обычный Bot API бот может скачать файл не больше 20 МБ.

### Переслать без скачивания

Если файл нужно просто передать дальше, скачивать его незачем. Отправьте его по токену:

```python
await ctx.bot.send_file_by_token(att.token, user_id=manager_id, file_type=att.type, caption="Новый документ")
```

Токен работает только в том мессенджере, откуда пришёл файл. Файл из Telegram так в MAX не переслать: его придётся скачать и отправить заново.

## Отправка без хендлера

Методы `ctx` работают внутри хендлера. Вне его, например в планировщике или в веб-приложении, пишите через сам бот. Получатель задаётся либо `user_id=` (личный чат человека), либо `chat_id=` (группа), ровно один из двух:

```python
from pathlib import Path

max_bot = MaxBot(MAX_TOKEN)

await max_bot.send_message("Напоминание о встрече", user_id=123)
await max_bot.send_file(Path("plan.pdf"), chat_id=-100, caption="План на неделю")
```

Используйте те же объекты ботов, что переданы в `run_polling`, а не создавайте новые: у каждого бота свои соединения с мессенджером.

Бот может написать только тому, кто уже открывал с ним чат. Если человек заблокировал бота или ни разу его не запускал, отправка закончится ошибкой, для которой `is_unreachable()` вернёт `True` (см. [Ошибки](errors.md#можно-ли-написать-человеку)).

Чтобы написать человеку сразу во все его мессенджеры или сделать рассылку, используйте [рассылки](broadcasts.md).
