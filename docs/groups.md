# Групповые чаты

Бот работает и в личных чатах, и в группах. Хендлеры те же самые, а `ctx.reply()` отвечает туда, откуда пришло событие.

```python
from matele import GROUP, ChatType, Context


@dp.command("stats", ChatType(GROUP))
async def stats(ctx: Context):
    count = await db.messages_in_chat(ctx.platform, ctx.chat_id)
    await ctx.reply(f"В этом чате {count} сообщений")
```

Где произошло событие, показывают `ctx.chat_type` (`PRIVATE` или `GROUP`) и `ctx.chat_id` (id группы или `None` в личном чате).

## Ответ в личку

`ctx.send_private()` пишет человеку в личный чат с ботом, даже если команда пришла из группы. Это удобно для всего, что не должно быть видно остальным:

```python
from matele import BotApiError, is_unreachable


@dp.command("mycode", ChatType(GROUP))
async def my_code(ctx: Context):
    try:
        await ctx.send_private(f"Ваш код: {await codes.issue(ctx.user.id)}")
    except BotApiError as exc:
        if not is_unreachable(exc):
            raise
        link = ctx.bot.deep_link(ctx.bot.me.username, "code")
        await ctx.reply(f"Сначала откройте личный чат с ботом: {link}")
        return
    await ctx.reply("Отправил код в личные сообщения")
```

Мессенджер не даёт боту написать первым: если человек ни разу не открывал бота или заблокировал его, отправка закончится ошибкой, для которой `is_unreachable()` вернёт `True`.

## Вход и выход участников

```python
@dp.member_update()
async def members(ctx: Context):
    update = ctx.member_update
    if update.is_me:
        if update.joined:
            await ctx.reply("Спасибо, что добавили! Команды: /help")
        return
    if update.joined:
        await ctx.reply(f"Добро пожаловать, {escape(update.member.name)}!")
```

В `ctx.member_update`:

- `member`: кто вошёл или вышел;
- `joined`: `True`, если вошёл, `False`, если вышел;
- `is_me`: событие про самого бота, его добавили в группу или удалили из неё;
- `from_user`: кто это сделал. Если человек вошёл или вышел сам, это он же.

## Команды для других ботов

Если в группе несколько ботов, команды пишут с адресом: `/help@other_bot`. Такие команды бот пропускает, они адресованы не ему. Команды без адреса и с адресом самого бота обрабатываются как обычно.

## Чтобы бот видел все сообщения

По умолчанию бот в группе видит не всё.

В Telegram включён режим приватности: бот получает только команды и ответы на свои сообщения. Чтобы получать все сообщения, отключите его в [@BotFather](https://t.me/BotFather) командой `/setprivacy`, потом удалите бота из группы и добавьте снова. Другой вариант: сделать бота администратором группы.

В MAX бот должен быть администратором группы с правом читать все сообщения.

## Состояния в группах

Состояние хранится отдельно для каждого человека в каждой группе. Если человек начал заполнять анкету в одной группе, его сообщения в другой группе или в личке не будут считаться ответами на её вопросы.

## Кнопки и меню в группах

Кнопку под сообщением бота может нажать любой участник группы. Если действие доступно не всем, проверяйте в хендлере, кто нажал (`ctx.user`). То же касается [меню в одном сообщении](menus.md): в группе все видят меню всех участников.

Каналы matele пока не обрабатывает, только личные чаты и группы.
