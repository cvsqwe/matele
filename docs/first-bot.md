# Первый бот

На этой странице мы установим matele, получим токены, напишем бота и запустим его в MAX и Telegram. На всё уйдёт минут пятнадцать.

## Установка

Нужен Python 3.11 или новее. Проверить версию можно командой `python --version`.

Создайте папку для бота, а в ней виртуальное окружение, чтобы пакеты бота не смешивались с остальными:

```bash
mkdir my-bot
cd my-bot
python -m venv .venv
source .venv/bin/activate      # в Windows: .venv\Scripts\activate
pip install matele
```

Вместе с matele установятся две зависимости: `httpx` для запросов к мессенджерам и `certifi` с корневыми сертификатами.

Часть возможностей требует дополнительных пакетов. Ставьте их, только когда они понадобятся:

| Что нужно | Как поставить |
|---|---|
| вебхуки | `pip install "matele[webhook]"` |
| хранение состояний в Redis | `pip install "matele[redis]"` |

Хранение состояний в SQLite и всё остальное работает без дополнительных пакетов.

## Токены

Токен это пароль бота: с ним любой может читать сообщения бота и писать от его имени. Не вставляйте токен в код и не публикуйте его в репозитории. Храните его в переменных окружения или в файле, который не попадает в git.

Для одного мессенджера достаточно одного токена. Второй можно добавить позже, код бота от этого не изменится.

### Telegram

Бота создаёт [@BotFather](https://t.me/BotFather):

1. Откройте чат с ним и отправьте `/newbot`.
2. Придумайте имя бота, оно показывается в заголовке чата.
3. Придумайте адрес бота. Он должен заканчиваться на `bot`, например `my_shop_bot`.
4. BotFather пришлёт токен вида `123456789:AAH...`.

### MAX

Боты создаются на платформе для бизнеса [business.max.ru](https://business.max.ru), там же выдаётся токен. Условия создания бота и актуальные инструкции смотрите в документации MAX для разработчиков на [dev.max.ru](https://dev.max.ru).

## Код

Создайте файл `bot.py`:

```python
import logging
import os

from matele import BotClient, Context, Dispatcher, escape
from matele.max import MaxBot
from matele.telegram import TelegramBot

dp = Dispatcher()


@dp.command("start", description="Начать")
async def start(ctx: Context):
    await ctx.reply(f"Привет, {escape(ctx.user.name)}! Напишите что-нибудь, и я повторю.")


@dp.message()
async def echo(ctx: Context):
    if ctx.text:
        await ctx.reply(escape(ctx.text))
    else:
        await ctx.reply("Я понимаю только текст")


def main():
    logging.basicConfig(level=logging.INFO)
    bots: list[BotClient] = []
    if token := os.environ.get("MAX_BOT_TOKEN"):
        bots.append(MaxBot(token))
    if token := os.environ.get("TELEGRAM_BOT_TOKEN"):
        bots.append(TelegramBot(token))
    if not bots:
        raise SystemExit("Задайте MAX_BOT_TOKEN или TELEGRAM_BOT_TOKEN")
    dp.run_polling(*bots)


if __name__ == "__main__":
    main()
```

Разберём по частям.

`dp = Dispatcher()` создаёт диспетчер. Он хранит хендлеры и для каждого пришедшего события решает, какой из них вызвать.

`@dp.command("start", description="Начать")` регистрирует хендлер для сообщения `/start`. Описание нужно, чтобы команда появилась в меню команд мессенджера: том списке, который открывается по кнопке рядом с полем ввода.

`@dp.message()` регистрирует хендлер для всех остальных сообщений. Команды проверяются раньше, поэтому `/start` сюда не попадёт.

`ctx` это контекст события. В нём есть всё о том, что случилось: кто написал (`ctx.user`), что написал (`ctx.text`), из какого мессенджера (`ctx.platform`). Через него же бот отвечает: `ctx.reply()` отправляет сообщение туда, откуда пришло событие.

`escape()` нужен потому, что matele отправляет сообщения как HTML. Имя человека и его текст приходят снаружи, и в них могут быть символы `<` и `&`, которые сломают разметку. `escape()` делает такой текст безопасным. Подробнее об этом в разделе [Файлы и форматирование](files.md#форматирование-текста).

`dp.run_polling(*bots)` подключается к мессенджерам и забирает новые события, пока вы не остановите бота. Это блокирующий вызов: программа остаётся в нём до остановки.

## Запуск

Задайте токены в переменных окружения и запустите файл:

```bash
export MAX_BOT_TOKEN=...
export TELEGRAM_BOT_TOKEN=...
python bot.py
```

В PowerShell переменные задаются так: `$env:TELEGRAM_BOT_TOKEN = "..."`.

В логе появится по строке на каждый мессенджер:

```text
INFO:matele.polling.max:MAX: polling as @my_bot (id 123)
INFO:matele.polling.telegram:Telegram: polling as @my_bot (id 456)
```

Откройте бота в мессенджере и отправьте `/start`. Бот поздоровается, а на любое другое сообщение ответит тем же текстом.

Остановить бота можно через Ctrl+C. Хендлеры, которые в этот момент работали, получат до 10 секунд, чтобы закончить.

## Если что-то не работает

Бот не отвечает, а в логе повторяется предупреждение `polling failed`. В его тексте есть причина. Чаще всего это неверный токен (ответ 401) или нет доступа к серверам мессенджера из вашей сети. matele не останавливается на таких ошибках: он повторяет попытки, а второй мессенджер в это время работает как обычно.

В логе Telegram ошибка 409 про webhook. Этим токеном раньше пользовался бот на вебхуках, и Telegram отправляет события туда. Как это исправить, написано в разделе [Переход обратно на polling](webhooks.md#переход-обратно-на-polling).

В логе Telegram ошибка 409 про другой запущенный экземпляр. С одним токеном может работать только один процесс с polling. Остановите второй.

Telegram недоступен из вашей сети. Передайте боту прокси: `TelegramBot(token, proxy="http://proxy.example.com:3128")`.

Бот в группе не видит обычные сообщения. Это настройки мессенджера, см. [Групповые чаты](groups.md#чтобы-бот-видел-все-сообщения).

## Ссылки на запуск

Ссылка вида `https://t.me/my_bot?start=promo` открывает бота и сразу передаёт ему значение. В MAX такая ссылка выглядит как `https://max.ru/my_bot?start=promo`. Такие ссылки удобно ставить в рекламу, на сайт или печатать в виде QR-кода: бот узнает, откуда пришёл человек.

В обоих мессенджерах значение приходит одинаково, как аргумент команды `/start`:

```python
@dp.command("start")
async def start(ctx: Context):
    if ctx.args == "promo":
        await ctx.reply("Вы пришли по промо-ссылке")
    else:
        await ctx.reply("Привет!")
```

Ссылку для текущего мессенджера строит сам бот:

```python
link = ctx.bot.deep_link(ctx.bot.me.username, "promo")
```

В значении безопасно использовать латинские буквы, цифры, `_` и `-`.
