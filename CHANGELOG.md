# Изменения

Версии нумеруются как `MAJOR.MINOR.PATCH`. До 1.0 ломающие изменения возможны в любой версии `0.x`, но каждое такое изменение записывается здесь в разделе «Ломающие изменения» вместе с тем, что нужно поправить в своём коде. Исправления без изменения API выходят как `PATCH`.

## Не выпущено

Первая версия. Что в ней есть:

- общий слой для MAX и Telegram: сообщения, кнопки, файлы, ответы на сообщения, статус «печатает…»
- роутеры, фильтры, middleware, состояния с хранилищами в памяти, SQLite и Redis
- типизированные данные кнопок
- групповые чаты и события входа и выхода участников
- меню в одном сообщении (`ctx.show()`)
- меню команд из `@dp.command(..., description=...)`
- мини-приложения: кнопка открытия и проверка `initData`
- рассылки во все мессенджеры человека (`Hub`)
- long polling и вебхуки (ASGI)
- весь MAX Bot API с моделями из официальной схемы, `TelegramApi.call()` для любого метода Telegram
- `FakeBot` для тестов без сети
