# Планы

Что уже сделано и что впереди. Порядок внутри разделов примерный.

## Готово

- общие типы, ошибки, типизированные кнопки
- роутеры, диспетчер, фильтры, middleware, состояния
- транспорты MAX и Telegram, весь MAX Bot API с моделями из официальной схемы
- групповые чаты, вебхуки, хранилища SQLite и Redis
- FakeBot для тестов без сети
- фото, видео, аудио, ответы на сообщения, статус «печатает…»
- меню команд из `@dp.command(..., description=...)`
- мини-приложения: кнопка открытия и проверка `initData` в обоих мессенджерах, пример с FastAPI
- CI на Windows и проверка покрытия тестами
- меню в одном сообщении: `ctx.show()`
- рассылки: `Hub` пишет человеку во все его мессенджеры, с лимитом скорости и повторами
- CHANGELOG, правила версий, публикация на PyPI из GitHub Actions по тегу
- документация на русском: https://cvsqwe.github.io/matele/

## До версии 0.1

Проверка на живых ботах. Всё пока проверено на фейковых серверах. Нужно прогнать примеры на настоящих ботах в обоих мессенджерах, особенно группы в MAX, загрузку файлов, вебхуки и мини-приложения (в MAX не проверено, что значение кнопки приходит именно в `start_param`).

Публикация на PyPI. Всё для неё готово (`RELEASING.md`), осталось один раз подключить репозиторий на сайте PyPI.

Документация на английском. Русская версия уже есть.

## После 0.1

- кнопки запроса контакта и геолокации
- события редактирования и удаления сообщений
